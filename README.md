# Bharat Kulwant — Developer Portfolio

A responsive, static portfolio website generated from the resume content.

## Files
- `index.html` — main portfolio
- `style.css` — responsive design, dark/light theme
- `script.js` — mobile navigation, theme toggle, reveal animations
- `resume/Bharat_Kulwant_MindLyft_AI_Resume.pdf` — resume download

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your actual email.
2. Add a professional photo if desired.
3. Add GitHub and live project URLs when available.
4. Upload the folder to GitHub Pages, Netlify, Vercel, or your preferred static host.

## Design
Dark developer/AI aesthetic with orange accent, responsive layout, accessible semantic sections, and no frontend framework dependency.
